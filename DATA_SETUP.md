# Local datasets

Raw datasets are intentionally excluded from this public repository.

Create a `data` directory in the repository root and place these files there:

- `Cleaned_English_Dataset.xlsx`
- `hindi_emails_merged.xlsx`

Start Jupyter from the repository root and open the notebook in `notebooks/`. The notebook checks the required files before proceeding. You can also set `PROJECT_DATA_DIR` to an absolute directory path before starting Jupyter.

Do not commit private email contents, personal information, or third-party material without appropriate permission.
